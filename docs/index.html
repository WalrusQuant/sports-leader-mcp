What You Get

Everything your agent needs

Connect once, query any sport. No API keys, no rate limits, no setup friction.

⚽

Live Scores & Schedules

Real-time scoreboards for every game in every league. Filter by date, week, or season type. Get event IDs for deeper data.

📊

Player Stats & Game Logs

Full season stats, game-by-game logs, home/away splits, and opponent breakdowns. Works for NFL, NBA, NHL, MLB, and more.

🏆

Standings & Leaders

Current standings for any league. League-wide statistical leaders — scoring, passing, rebounding, whatever the sport tracks.

💰

Betting Odds

Spreads, moneylines, and over/unders from DraftKings, FanDuel, Caesars, BetMGM, ESPN BET, and Bet365.

🏅

Full Game Data

Boxscores, play-by-play, win probability timelines, and game summaries. The richest view of any game in one call.

📰

News, Injuries & Transactions

Real-time news feeds, league-wide injury reports, and transaction logs — signings, trades, waivers, all in one place.
